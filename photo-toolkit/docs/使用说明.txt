照片工具 — 使用说明
========================================

纯本地、免安装的照片整理与管理工具。双击「照片工具.exe」即可使用，
不需要命令行，也不需要安装任何运行库（依赖系统自带的 PowerShell 5.1）。


一、系统要求
----------------------------------------
* Windows 10 / 11（64 位）
* Windows PowerShell 5.1（系统自带）
* .NET Framework 4.x（系统自带）


二、首次使用
----------------------------------------
1. 把整个「照片工具」文件夹放到任意位置（建议非系统盘）
2. 双击「照片工具.exe」
3. 点「更改照片库路径...」，选择照片库根目录（例如 D:\照片库）
4. 之后：
   - 「导入照片」：从存储卡或任意文件夹把照片整理进库
   - 「管理照片」：浏览、筛选、打分、标记、删除


三、导入照片
----------------------------------------
选择照片来源（存储卡根目录或其中的 DCIM 文件夹），程序自动识别相机与拍摄时间，
按 相机\年\年-月 归档；视频进入 相机\视频。

默认是「仅预演」，只在窗口里列出计划，不改动任何文件。
确认无误后取消勾选「仅预演」，再点「开始导入」才真正执行。

开关：
  复制 / 移动     —— 导入后卡上文件是否保留
  快速判重        —— 按大小+修改时间判断，跳过 MD5（更快）
  读取 EXIF       —— 更准确但更慢；关闭后用文件修改时间
  并发            —— 复制线程数，默认「自动(1)」最稳

导入过程中的重复文件（内容相同）会自动跳过；同名但内容不同会改名为 xxx_1.JPG。


四、管理照片
----------------------------------------
缩略图网格浏览，每页 60 张。

筛选：相机 / 年 / 月 / 文件名关键字 / 标记状态

快捷键：
  1 ~ 5     打星
  0 或 U    清除星级与标记
  X         标记「淘汰」
  P         标记「保留」
  ← / →     上一张 / 下一张
  PageUp/Dn 翻页
  双击      用默认程序打开原图

同一张照片的 JPG 与 NEF 合并为一个格子（标 RAW+JPG），打分同时作用于两个文件。
删除走回收站，可还原。

首次打开会自动建索引（约 2~3 分钟 / 7 千张），之后每次启动只做增量检查（约 2 秒）。


五、目录结构
----------------------------------------
  照片工具\
  ├─ 照片工具.exe        启动器
  ├─ config.ini          配置（照片库路径）
  ├─ 使用说明.txt        本文件
  └─ app\                实际程序（6 个 PowerShell 脚本）

照片库目录下会生成 _缓存\：
  index.json   索引
  marks.json   评分与标记
  thumbs\      缩略图


六、常见问题
----------------------------------------
Q: 提示「照片库路径不存在」？
A: 点「更改照片库路径」重新指定，或确认移动硬盘已插好。

Q: exe 被杀毒软件拦截？
A: 它只是启动器（调用系统自带 PowerShell）。加入白名单，
   或右键 → 属性 → 勾选「解除锁定」。

Q: 换照片库路径后旧评分还在吗？
A: 评分存在各库自己的 _缓存\marks.json，跟随目录走。

Q: 能只拷贝 exe 给别人吗？
A: 不行，需要整个文件夹（app 子目录才是程序本体）。

Q: 修改脚本后中文变乱码？
A: .ps1 必须保存为 UTF-8 带 BOM，否则 PowerShell 5.1 按 ANSI 读取会报错。
